# PremiumShop Pro
Premium responsive e-commerce template for resale.

## Included
- Responsive storefront
- Product search and category filters
- Product detail modal
- Shopping cart with localStorage
- Wishlist
- Checkout demo flow
- Account and orders pages
- Admin dashboard demo
- Node.js/Express API starter
- Documentation and licensing notes

## Run
1. Open a terminal in `backend`
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000

The frontend is served from `frontend/`.

## Important
This is a commercial-ready template/demo architecture. Real payments, production authentication, inventory persistence, email, and database credentials must be connected by the buyer before production use.
