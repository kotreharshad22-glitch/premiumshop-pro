# Setup Guide

## Requirements
- Node.js 18+
- npm

## Start
cd backend
npm install
npm start

Then visit http://localhost:3000

## Customization
Edit `frontend/css/style.css` for theme styling.
Edit `frontend/js/app.js` for products and cart behavior.
Edit `frontend/index.html` for storefront content.

## API
GET /api/health
GET /api/products
